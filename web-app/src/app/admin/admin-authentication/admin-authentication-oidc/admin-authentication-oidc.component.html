Credentials

Client Identifier Obtained from the OpenID server when you register your app. Not considered secret. Client Secret Obtained from the OpenID server when you register your app. Keep this secret.

URLs

Authorization URL Endpoint to obtain authorization grant from the resource owner. Token URL Endpoint to exchange an authorization grant for an access token. User Profile URL Endpoint accessed after obtaining an access token to retrieve user information (API server). Issuer URL Endpoint of your identity provider — the entity that issues a set of claims.

Access

Scope Scope values indicating which parts of the user's account to access (comma-separated). Must include 'openid'. Advanced

User Profile

Profile ID Property The id property returned in the user profile. Default: 'sub'. Display Name Property The display name property returned in the user profile. Default: 'name'. Email Name Property The email property returned in the user profile. Default: 'email'.
