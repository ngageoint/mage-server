Client Identifier Obtained from the OAuth 2.0 server when you register your app. Not considered secret. Client Secret Obtained from the OAuth 2.0 server when you register your app. Keep this secret.

URLs

Authorization URL Endpoint to obtain authorization grant from the resource owner. Token URL Endpoint to exchange an authorization grant for an access token. User Profile URL Endpoint accessed after obtaining an access token to retrieve user information (API server).
