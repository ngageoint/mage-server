Account Lock

Account Lock {{ choice.title }} MAGE can lock user accounts after a number of invalid login attempts for a certain amount of time.

Account Lockout Threshold

Number of invalid login attempts after which the user's account will be locked.

Account Lockout Interval (Seconds)

Amount of time in seconds a user's account will remain locked after reaching the lockout threshold.

Enable Max Lockout

Max Lockout {{ choice.title }} MAGE can disable user accounts if a user locks their account a certain number of times.

Max Lockout Threshold

Number of times a user account can be locked before it is disabled. Disabled accounts must be re-enabled by an admin.
