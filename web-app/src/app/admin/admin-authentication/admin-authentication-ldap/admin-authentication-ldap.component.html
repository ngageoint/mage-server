Server

URL This is the location of the LDAP server. Begins with the prefix of ldap or ldaps.

Authentication

Bind DN The bind DN is the credential used to authenticate against an LDAP. It usually comes with a password set in the bind credentials. Bind Credentials Password used to authenticate against an LDAP.

User Search

Search Base The base DN from which to search for users by username. Search Filter LDAP search filter with which to find a user by username. Requires knowledge of the LDAP search filter grammar. Search Scope {{ scope.viewValue }} Scope of the search. Default: sub.

Group Search

Group Search Base The base DN from which to search for groups. Group Search Filter LDAP search filter for groups. Requires knowledge of the LDAP search filter grammar. Group Search Scope {{ scope.viewValue }} Scope of the search. Default: sub. Advanced

Authentication

User Bind Property Property of the LDAP user object to use when binding to verify the password. Default: dn.

Interpolation

Group DN Property The property of user object to use in 'dn' interpolation of groupSearchFilter. Default: 'dn'.

User Profile

Profile ID Property The id property returned in the user profile. Default: 'cn'. Display Name Property The display name property returned in the user profile. Default: 'givenname'. Email Name Property The email property returned in the user profile. Default: 'mail'.
