# Working with Events

[← Back to Navigating MAGE](../Navigating_MAGE.md)

## What's an Event?

An event is the scope everything else in MAGE happens inside — your observations, the people you can see, and the layers and feeds available to you. You'll only see and contribute to the events you've been given access to. See [Event](../domain.md#event) in the Domain Model for the full concept.

**Note:** your admin creates events and decides who participates in them, and which forms, layers, and feeds are available inside each one — you can't create an event yourself. What you control is which of your events you're actively working in.

## Selecting an Event

**Why:** All data in MAGE — the map, observations, people, feeds — is scoped to an Event. Nothing shows up until you pick one.

1. Click the event name at the top of the screen (it reads "Select Event" if none is active yet).
2. Use the search box to find an event by name, or scroll the list.
3. Click an event to switch to it — the map and tabs refresh to show that event's data. If you belong to more than one event, repeat these steps any time to switch; nothing from your previous event carries over.

## Common Issues

**A user or team can't see an event that should be available to them.** Being added to an event is what grants access — a user isn't automatically included just because they're on a team that exists, or because an admin created the event. Check that the user's team has actually been added to the event, and that the user is a member of that team.
